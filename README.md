# QR Code Generator

A simple, responsive QR code generator built with HTML, CSS, and JavaScript.
Enter text or a website URL, generate a QR code, and download it as a PNG.

## Run locally

Open `index.html` in a browser. The QRCode.js library is loaded from jsDelivr, so
an internet connection is needed to generate QR codes.

## Files

- `index.html` contains the page structure.
- `style.css` contains the responsive styles.
- `script.js` handles QR code generation, validation, and PNG downloads.
